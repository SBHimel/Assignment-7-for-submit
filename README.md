🌟 KeenKeeper
📌 Project Description

KeenKeeper is a smart friendship management web app that helps you keep track of your relationships and stay connected with people who matter most. It allows users to manage friends, monitor interaction frequency, and log activities like calls, messages, and meetups through an intuitive timeline system.

🚀 Technologies Used
React.js
React Router
Context API
Tailwind CSS
Recharts (for analytics visualization)
React Hot Toast (for notifications)
✨ Key Features
🔹 1. Activity Timeline System

Users can log interactions like Call, Text, and Video with friends. All activities are stored and displayed in a dynamic timeline.

🔹 2. Smart Filtering

Filter timeline activities by type (Call, Text, Video) to quickly view specific interactions.

🔹 3. Analytics Dashboard

Visual representation of user interactions using charts (Pie Chart) to understand communication patterns.

💡 Additional Highlights
Responsive UI design
Dynamic icon & color based on actions
Real-time toast notifications
Clean and user-friendly interface
